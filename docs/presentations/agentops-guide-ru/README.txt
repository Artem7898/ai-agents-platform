AgentOps: создание агента и обработка заявок

MP4, 1920×1080, H.264, 25 кадров/с. Без озвучки; русские титры встроены в видео и приложены в SRT.
Изолированный учебный стенд: ответы LLM имитируются, эта пометка видна весь ролик. PostgreSQL, создание агента, workflow, подтверждение, HTTP-запись и перезапуск worker настоящие. Нажатия в интерфейсе автоматизированы; данные вымышленные. Качество настоящих весов модели не проверяется.

В кадре: создание агента, привязка к подготовленному workflow, заявка ES-001, Confirmar, аварийная остановка worker после записи, восстановление того же запуска без дубля, Corregir → Acceso для второй заявки, журнал событий.

Секреты, пароли, cookie и конфигурация доступа в пакет не включены.
